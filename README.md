# KHK Software

I build frameworks, guardrails, and the occasional power tool for getting useful work out of AI agents without letting the whole thing dissolve into an indecipherable skein of spaghetti.

Some of this is polished. Some of it is still wearing a hard hat. All of it exists because “the agent will probably remember” is not a control mechanism.
